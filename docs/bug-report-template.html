Severity Guide

  • Critical: System unusable, order blocked, data loss, login blocked, production outage.
  • High: Major feature broken but workaround may exist.
  • Medium: Important issue with limited business impact.
  • Low: Minor issue, cosmetic bug, wording issue.

Priority Guide

  • P1: Must fix immediately.
  • P2: Fix in current release cycle.
  • P3: Fix when schedule permits.
  • P4: Nice to have / backlog item.
