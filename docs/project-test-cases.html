Astha Express Manual Test Cases

ProjectAstha Express
Document PurposeManual QA checklist for storefront, checkout, admin, catalog, marketing, media, and settings flows.
Prepared ByOpenAI Codex
Suggested UseRun P1 cases first, then P2, then P3. Mark Pass/Fail and capture screenshots for failed cases.

1. Test Execution Notes

  • Use a fresh browser session for guest checkout tests.
  • Use another logged-in session for customer account tests.
  • Keep at least one active product, one product with variation, one banner, one campaign, and one coupon available before starting.
  • If possible, test on both desktop and mobile viewport.
  • For each failed test case, capture steps, screenshot, expected result, actual result, and affected URL.

2. Priority Definition

  • P1: Core revenue or admin-blocking flow.
  • P2: Important business/admin feature.
  • P3: Secondary UX, content, or regression check.

10. Recommended Regression Checklist

  • Homepage loads after any admin content/image update.
  • Product details page still works after product edit.
  • Add to cart works for simple and variable products.
  • Checkout still works after coupon/shipping/settings changes.
  • Admin order list and POS work after catalog changes.
  • Media library delete does not break in-use image references.
  • Customer login, profile update, and order history remain functional.
