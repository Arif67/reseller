Astha Express Smoke Test Cases

This document is for quick post-deploy or post-change smoke testing. Run these cases first to confirm that the most important user and admin flows are still working.

Execution Notes

  • Run in a fresh browser session.
  • Keep one active product, one category, one admin account, and one customer account ready.
  • Capture screenshot immediately if any smoke case fails.

Smoke Test Cases

ID Module Scenario Steps Expected Result
SM-01 Homepage Homepage loads Open homepage. Homepage opens without error, broken layout, or broken images.
SM-02 Category Category page opens Open any category page. Products load correctly.
SM-03 Product Product details open Open any active product details page. Product name, price, image, and order button appear correctly.
SM-04 Cart Add to cart works Add one product to cart. Cart count and cart summary update correctly.
SM-05 Cart Cart page works Open cart page and change quantity. Subtotal and total update correctly.
SM-06 Checkout Checkout page opens Open checkout page with item in cart. Checkout page loads and required fields are visible.
SM-07 Checkout Order placement works Place one test order with valid information. Order is created and success page appears.
SM-08 Customer Login Customer login works Login with valid customer account. Customer account/dashboard opens correctly.
SM-09 Customer Orders Customer order list works Open customer orders page. Placed order appears in order list.
SM-10 Admin Login Admin login works Login to admin panel. Admin dashboard opens without error.
SM-11 Admin Orders Admin order list works Open admin orders list after placing test order. New order is visible with correct amount and customer details.
SM-12 POS POS page works Open POS page and search a product. Product search and cart add work correctly.
SM-13 Media Library Media upload works Upload one image from media library. Image appears in media grid.
SM-14 Category Media Picker Media picker selection works Create/edit category and select image from media library. Selected image saves correctly.
SM-15 Banner Banner image save works Create or edit banner using upload or media library. Banner saves successfully.
SM-16 Brand Brand image save works Create or edit brand with image. Brand saves and image preview is correct.
SM-17 Coupon Coupon image and save works Create or edit coupon with image. Coupon saves successfully.
SM-18 User Admin user image save works Create or edit admin user with image. User saves successfully.
SM-19 Settings General settings save works Update white logo, dark logo, and favicon. Settings save successfully and frontend uses updated assets.
SM-20 SEO Settings SEO settings page works Open SEO settings and save a small change. Page saves without error.
