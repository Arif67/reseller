UAT Scope

  • Customer browsing and order placement
  • Customer account and order history
  • Admin product, media, banner, brand, coupon, and settings management
  • POS and order management
  • Business-critical configuration and content update capability

Acceptance Criteria

  • All critical business flows should pass.
  • No blocker or data-loss issue should remain open.
  • Admin should be able to manage catalog, media, order, and settings without developer support.
  • Frontend should allow a customer to browse, add to cart, and place an order successfully.
